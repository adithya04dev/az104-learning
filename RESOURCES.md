# AZ-104 Resources

## Knowledge

- [Microsoft Learn: Study guide for Exam AZ-104](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104)
  The source of truth for the current skills measured, domain weights, exam updates, and official preparation links. Recheck before booking and again shortly before taking the exam.
- [Microsoft Learn: AZ-104 prerequisites](https://learn.microsoft.com/en-us/training/paths/az-104-administrator-prerequisites/)
  Covers Cloud Shell and infrastructure deployment prerequisites. Use selectively because the learner already has AZ-900 foundations.
- [Microsoft Learn: Manage identities and governance](https://learn.microsoft.com/en-us/training/paths/az-104-manage-identities-governance/)
  Official modules for Microsoft Entra objects, Azure RBAC, subscriptions, Policy, and SSPR. Use to close gaps found by the diagnostic and labs.
- [Microsoft Learn: Create, invite, and delete Microsoft Entra users](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-create-delete-users)
  Current guidance on internal members, external guests, user creation, invitation, and least-privileged administrative roles.
- [Microsoft Learn: Enable Microsoft Entra self-service password reset](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr)
  Current prerequisites and rollout procedure for group-scoped SSPR, authentication registration, testing, and notifications.
- [Microsoft Learn: Steps to assign an Azure role](https://learn.microsoft.com/en-us/azure/role-based-access-control/role-assignments-steps)
  Authoritative principal-role-scope model, least-privilege selection guidance, inheritance, and role-assignment prerequisites.
- [Microsoft Learn: Azure Policy overview](https://learn.microsoft.com/en-us/azure/governance/policy/overview)
  Definitions, initiatives, assignments, effects, evaluation, compliance, and remediation.
- [Microsoft Learn: Resource locks](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/lock-resources)
  Lock levels, inheritance, control-plane boundary, permissions, and service-specific consequences.
- [Microsoft Learn: Resource tags](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/tag-resources)
  Tag scope, permissions, cost use, limitations, and the fact that tags do not inherit automatically.
- [Microsoft Learn: Azure management groups](https://learn.microsoft.com/en-us/azure/governance/management-groups/overview)
  Hierarchy, inheritance, root management group, limits, and multi-subscription governance.
- [Microsoft Learn: Create and manage budgets](https://learn.microsoft.com/en-us/azure/cost-management-billing/costs/tutorial-acm-create-budgets)
  Budget scopes, permissions, actual and forecast alerts, evaluation timing, and the critical fact that budgets do not stop resources.
- [Microsoft Learn: Implement and manage storage](https://learn.microsoft.com/en-us/training/paths/az-104-manage-storage/)
  Official modules for storage accounts, Blob Storage, Azure Files, replication, access, and security.
- [Microsoft Learn: Deploy and manage compute resources](https://learn.microsoft.com/en-us/training/paths/az-104-manage-compute-resources/)
  Official modules for VMs, availability and scale, App Service, and containers.
- [Microsoft Learn: Configure and manage virtual networks](https://learn.microsoft.com/en-us/training/paths/az-104-manage-virtual-networks/)
  Official modules for VNets, NSGs, peering, routes, DNS, load balancing, and Network Watcher.
- [Microsoft Learn: Monitor and back up Azure resources](https://learn.microsoft.com/en-us/training/paths/az-104-monitor-backup-resources/)
  Official modules for Azure Monitor, Azure Backup, and recovery.
- [Microsoft Learn: Free AZ-104 Practice Assessment](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/practice/assessment?assessment-type=practice&assessmentId=21&practice-assessment-type=certification)
  Use first as a diagnostic, then later as one readiness signal. Review every rationale; do not memorize questions.
- [Microsoft exam sandbox](https://aka.ms/examdemo)
  Use near the exam to become familiar with the interface and question types rather than losing time to navigation.

## Wisdom (Communities)

- [Microsoft Q&A: Azure](https://learn.microsoft.com/en-us/answers/tags/133/azure)
  Use for real configuration and troubleshooting questions; compare answers with current Microsoft documentation.
- [Microsoft Azure Community Support](https://azure.microsoft.com/en-us/support/community/)
  Official directory of community support channels. Use to observe how practitioners diagnose real operational problems.

## Gaps

- Confirm whether the learner has an Azure subscription or employer-provided sandbox for hands-on work.
- Confirm whether Azure CLI, PowerShell, and a Bicep-capable editor are available locally.
