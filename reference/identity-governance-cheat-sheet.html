AZ-104 rapid reference

Identity & governance

Use after completing the lessons. Ask: identity, authorization, compliance, protection, classification, hierarchy, or cost notification?

Identity lifecycle

Internal member

Typical employee identity managed/authenticated in the tenant.

External guest

External relationship; normally authenticates through an external identity.

Groups

Represent job function or entitlement population. Prefer group-based assignments for many people.

SSPR

Scope + license + role + registered allowed method + test. It does not grant Azure resource access.

Azure RBAC

Principal + Role + Scope = role assignment

Scopes: management group → subscription → resource group → resource.

Parent assignments inherit downward. Start with the most restrictive role and narrowest workable scope.

Entra roles administer directory capabilities. Azure RBAC roles authorize Azure resource actions.

Policy model

Definition describes rule + effect.

Initiative groups definitions.

Assignment binds to scope + parameters/exclusions.

Evaluation produces compliance/effect.

Remediation corrects eligible existing resources; it is not implied merely by assignment.

Common effects: Audit, Deny, Modify, DeployIfNotExists.

Locks, tags, budgets: traps

CanNotDelete: updates allowed, deletion blocked.

ReadOnly: control-plane updates and deletion blocked.

Locks do not protect data-plane content.

Tags do not inherit automatically; never store secrets in tags.

Budgets notify and may trigger configured actions; they do not inherently stop resources.

Management groups

Governance scope above subscriptions. Policy and RBAC can inherit to descendants.

One hierarchy per directory, with one root management group. Assign at root only for true global requirements.

Each management group/subscription has one parent; a management group may have many children.

Fast exam algorithm

  1. Underline the required outcome.
  2. Separate identity from authorization.
  3. Select the correct control/tool.
  4. Choose least privilege and narrowest workable scope.
  5. Trace inheritance downward.
  6. Check control plane vs data plane.
  7. Reject answers that claim budgets stop spend, tags inherit, or locks grant access.
